# German Traffic Sign AI

An end-to-end computer vision project for recognizing German traffic signs using deep learning.

## Project Goal

Build and deploy a machine learning system that classifies German traffic signs from images and later extends toward robustness testing, explainability, and deployment.

## Planned Features

- Dataset exploration
- Image preprocessing
- CNN baseline model
- Transfer learning model
- Model evaluation
- Robustness testing
- Grad-CAM explainability
- Streamlit web app
- Cloud deployment

## Tech Stack

- Python
- TensorFlow/Keras
- OpenCV
- Scikit-learn
- Streamlit
- Git/GitHub

## Dataset Attribution

This project uses the German Traffic Sign Recognition Benchmark (GTSRB), a public benchmark dataset for multi-class traffic sign classification.
